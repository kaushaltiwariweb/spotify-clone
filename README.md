# 🎵 Spotify Clone

A responsive web application cloning the core user interface of Spotify, built with HTML and CSS.

---

## 🚀 Live Demo

[View Live Project](https://kaushaltiwariweb.github.io/spotify-clone/)

---

## ✨ Features

- **Responsive Design:** Optimized for different screen sizes (desktop, tablet, mobile).
- **Sidebar Navigation:** Spotify-style sidebar with navigation links and playlist library.
- **Music Player Bar:** Audio player control interface complete with playback controls, progress bar, and volume slider.
- **Main Dashboard:** Dynamic grid layouts displaying featured playlists, top charts, and recent releases.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic layout and structure.
- **CSS3:** Custom styles, Flexbox, CSS Grid, and responsive media queries.
